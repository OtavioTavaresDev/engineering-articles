Building Lightweight Security Automation with Python

Practical approaches for automating repetitive security operations without overengineering.

May 5, 2026 10 min read

Why Python Wins for Security Automation

Security teams don't need enterprise service buses or workflow engines. They need glue code that parses logs, calls APIs, and sends alerts. Python's ecosystem — requests, pandas, asyncio, and libraries like python-dotenv — is the perfect fit for lightweight, maintainable automations.

The key is resisting the urge to overarchitect. A 50-line script that runs on a cron job often beats a microservice with a message queue.

Example 1: IOC Enrichment Pipeline

You have a CSV of suspicious IPs from firewall logs. You need to enrich them with VirusTotal, AlienVault OTX, and Shodan. A script using asyncio can fetch all three APIs concurrently: 

import asyncio
import aiohttp
from typing import List

async def enrich_ip(session, ip):
    vt_url = f"https://www.virustotal.com/api/v3/ip_addresses/{ip}"
    headers = {"x-apikey": os.getenv("VT_API_KEY")}
    async with session.get(vt_url, headers=headers) as resp:
        return await resp.json()

async def main(ips: List[str]):
    async with aiohttp.ClientSession() as session:
        tasks = [enrich_ip(session, ip) for ip in ips]
        results = await asyncio.gather(*tasks)

Example 2: SIEM Alert Triage Bot

Use Python to poll a SIEM's API, filter low-priority alerts, and post only the critical ones to Slack or Microsoft Teams. Add a one-click "suppress for 24h" button using message interactions. 

import requests
from datetime import datetime, timedelta

def fetch_critical_alerts(since_minutes=15):
    since = datetime.utcnow() - timedelta(minutes=since_minutes)
    query = f'severity: "high" AND timestamp: [{since.isoformat()} TO *]'
    response = requests.post(SIEM_API, json={"query": query})
    return response.json()["alerts"]

def post_to_slack(alerts):
    for alert in alerts:
        slack_payload = {"text": f"*CRITICAL*: {alert['rule_name']}\n{alert['description']}"}
        requests.post(SLACK_WEBHOOK, json=slack_payload)

Example 3: Automated Log Parsing for Custom Detection

Your team has a custom app that logs authentication attempts. Instead of waiting for a SIEM integration, write a script that tails the log, parses failed logins, and triggers a webhook when a threshold is exceeded. 

import time
from collections import defaultdict
from tailer import follow

failed_attempts = defaultdict(int)

for line in follow(open("/var/log/custom-app/auth.log")):
    if "Authentication failed for user" in line:

When Not to Use Python

If your automation needs state, retries, or a web UI, consider a purpose-built tool like Tines, Zapier, or n8n. Python excels at one-off scripts and data transformations — but for long-running services, you'll need error handling, logging, and observability that's easier to get from dedicated automation platforms.
